# Project Aura v1.2.1 beta

Beta firmware for Aura AQ 4.3-inch and 7-inch controllers.

## Changes since the October 7 beta

- Reduces boot-logo storage and static PSRAM use by about 1.2 MiB while keeping
  its appearance, position and version label.
- Adds recent HTTP transfer failures to the downloadable diagnostic report,
  including the requesting client and memory/network context. This helps
  investigate interrupted page loads; it does not claim to resolve issue #158.
- Clears saved SEN69C VOC state completely during a factory reset.
- Updates GT911 touch handling and renders 180-degree rotation directly on the
  7-inch controller. Changing orientation applies after a restart.
- Corrects the calibration interface and reports an absent optional SEN0466
  as informational instead of a warning.

## Earlier changes in 1.2.1 beta

- Fixes touch input stopping after approximately 24.9 days of continuous
  operation. The display and web dashboard could keep working while touch
  stopped responding. The expired startup guard is now cleared permanently.
- Adds support for the DFRobot SEN0321 ozone sensor, including its warmup state,
  display, web dashboard and MQTT readings.
- Restores SD logging after recoverable I/O failures and provides a retry
  action and clearer storage diagnostics in the web dashboard.
- Aligns the remaining SFA40 STOP-command waits with Sensirion's reference
  drivers. This does not change HCHO calibration or temperature compensation.
- Migrates the firmware to ESP-IDF 6.1 and the native I2C master API.
- Updates Arduino-ESP32 to 3.3.12, LVGL to 9.6 and mDNS to 1.14.0.
- Updates the EEZ interface for LVGL 9 and corrects its task stack allocation.
- Adds automatic identification of SEN66 and SEN69C, with separate drivers.
- Adds SEN69C integrated HCHO readings and an independent CO2 warmup indicator.
  A detected SEN69C supplies HCHO without probing separate SFA30/SFA40 modules.
- Preserves SEN66 operation and separate SFA30/SFA40 support when SEN66 is fitted.

## Hardware compatibility

Use the firmware for your exact controller model. The 4.3-inch target is
`aura-aq-v1`; the 7-inch target is `aura-aq-7-v1` with profile `7_dual_i2c`.
The established 7-inch sensor wiring remains SDA GPIO44 and SCL GPIO6.

Read the [Aura AQ 1.2.0 update guide](https://aura-aq.com/blog/aura-aq-1-2-0)
before updating either model. A 7-inch controller still using pre-1.2.0 wiring
or firmware must complete the full migration procedure through the Web
Installer; do not use OTA for that first migration.

## Beta status

SEN69C support has been tested on physical hardware and confirmed working.
The touch timing fix is covered by regression tests, including the uptime
values from issue #157; confirmation on the reporter's device is pending.

Software tests and successful builds do not establish physical qualification
of these exact beta binaries. Earlier device and overnight test results apply
to their recorded candidates, not automatically to this build.

If a problem occurs, save a diagnostic report from `http://<your-aura-ip>/diag`
before restarting or unplugging Aura. Include the firmware build ID and your
controller model with the report.
