# Project Aura v1.2.1 beta

Beta firmware for Aura AQ 4.3-inch and 7-inch controllers.

## Changes

- Migrates the firmware to ESP-IDF 6.1 and the native I2C master API.
- Updates LVGL to 9.5 and regenerates the EEZ interface for LVGL 9.
- Corrects the LVGL task stack allocation for the updated interface.
- Adds automatic identification of SEN66 and SEN69C, with separate drivers.
- Adds SEN69C integrated HCHO readings and an independent CO2 warmup indicator.
  A detected SEN69C supplies HCHO without probing separate SFA30/SFA40 modules.
- Preserves SEN66 operation and separate SFA30/SFA40 support when SEN66 is fitted.
- Removes the obsolete warning about a possibly unchanged precompiled IPC stack.

## Hardware compatibility

Use the binary for your exact controller model. The 4.3-inch target remains
`aura-aq-v1`; the 7-inch target remains `aura-aq-7-v1` with profile `7_dual_i2c`.
The established 7-inch sensor wiring remains SDA GPIO44 and SCL GPIO6.

Controllers still using pre-1.2.0 wiring or firmware must follow the
[1.2.0 migration instructions](v1.2.0.md) before using this release.

## Beta validation scope

The implementation preceding this version change was exercised on both
controller models with SEN66. USB app readback, startup, sensor data, display
diagnostics and user screen/touch checks passed on the recorded candidates.
The longer overnight run covered an earlier migration candidate and included
a gap in computer network observation.

SEN69C hardware was not available for physical validation. Its support is
experimental in this beta and needs testing with a real SEN69C.

The final 1.2.1-beta binaries and installer packages need their own artifact
identity and installation records before publication. Earlier candidate
results must not be presented as an overnight test of these final binaries.
