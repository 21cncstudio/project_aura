# Aura AQ 1.2.1 beta — 2dcd878

Released 4 November 2026 for Aura AQ 4.3-inch and 7-inch dual-I2C.

## Changes since beta 1625a09

- Fixes HTTP connection ownership and cleanup after interrupted requests. Limits request-body waits and lets screen wake-up interrupt a stalled transfer.
- Improves Wi-Fi setup: safer AP scanning across country channels, connection lease handling, captive DNS, and confirmation that the browser received saved settings.
- Restores compatibility with older phone captive browsers. Rescan uses XMLHttpRequest and retries after errors or timeouts without requiring async functions, fetch, AbortController or NodeList.forEach.
- Improves station connection retry handling. Transient events during the initial connection window are informational; persistent connection failures remain warnings.
- Completed slow HTTP writes remain in diagnostic counters without producing warning noise. Failed writes and request-body timeouts remain visible.
- Both displays use the established 16 MHz pixel clock. No 12 MHz mode is included.

Earlier beta improvements remain: lower startup-logo memory use, downloadable HTTP failure reports, touch calibration and long-uptime touch fixes, SEN0321 support, SEN69C factory-reset correction and SD logging recovery.

## Validation and limits

These are the exact, unmodified firmware images tested on both models: screen and touch, full power removal, wake by touch during a stalled POST, and Wi-Fi setup using a Pixel 3. Automated firmware and browser regression checks passed. A 10-hour 4.3-inch direct MQTT-to-Home-Assistant observation had no device restart, MQTT offline event or new device network warning; two HTTP observation timeouts recovered and their cause remains unknown.

This is a beta. The cause of the external reports in issue #158 has not been established; these fixes are not proof that every reported symptom is resolved. Try one device first. Full Web Installer installation and the v1.2.0-to-this-beta OTA transition have not been separately repeated on hardware for this release.

## Installation

Choose the file and installer target for your exact display model. Web Installer Update preserves settings and LittleFS; Full Install replaces the filesystem and settings. Manual OTA requires the official 1.2.0 firmware or an already migrated official 1.2.1 beta of the same model. For older firmware, follow the complete Aura AQ 1.2.0 update guide first.

For the 7-inch model, all 1.2.0 wiring changes must already be complete: sensor I2C uses SDA GPIO44 / SCL GPIO6. Do not use OTA for the first migration from older firmware or on unchanged wiring. Never install a 4.3-inch image on a 7-inch controller, or the reverse.

This is the regular Aura firmware line with direct MQTT / Home Assistant support. Firmware with Aura Hub support remains a separate line.
