# Native ESP-IDF installer packages

On the IDF 6.1 migration branch, `scripts/build_idf.ps1` builds the app,
bootloader, partition table, initial OTA data and LittleFS image together.
LittleFS uses the pinned component's image builder, the partition CSV size
and the firmware's filename limit. It is not added to the normal flash target.

After a successful complete build, the wrapper records all five sizes and
SHA256 hashes in `build-idf-<profile>/generated/release-artifacts.json`, bound
to the generated source commit, build ID and hardware identity.

Commit all build inputs, then prepare each signed beta package:

```powershell
.\scripts\prepare_installer_release.ps1 -Env project_aura `
  -Version 1.2.1-beta -Channel beta -IdfPath <idf-checkout> -ToolsPath <idf-tools>
.\scripts\prepare_installer_release.ps1 -Env project_aura_7 `
  -Version 1.2.1-beta -Channel beta -IdfPath <idf-checkout> -ToolsPath <idf-tools>
```

Use `-SkipBuild` only after that complete build. It requires the existing stamp
and rejects stale identities or changed binaries; it never stamps old outputs.
`-BuildSystem platformio` retains the older packaging layout for older branches.

| Native output | Signed package name | Full Install offset |
| --- | --- | --- |
| `bootloader/bootloader.bin` | `bootloader.bin` | `0x0000` |
| `partition_table/partition-table.bin` | `partitions.bin` | `0x8000` |
| `ota_data_initial.bin` | `boot_app0.bin` | `0xE000` |
| `aura_aq.bin` | `firmware.bin` | `0x10000` |
| `littlefs.bin` | `littlefs.bin` | `0xC90000` |

The package keeps Aura Admin's existing names and signature schema. The OTA
initialization file is generated by this IDF build, not copied from an Arduino
SDK. Update mode contains only the app. Full Install and Update semantics on
the site are unchanged; a physical installer test is separate evidence.

Packages are stored under `release-assets/v1.2.1-beta/<hardware-target>/`.
Preparation and signing do not upload anything. Aura Admin import creates a
Draft; Publish/Current, site deployment and GitHub publication are separate.
The site's exact-version policy for 7-inch must match the signed beta version
before promotion. Do not remove model checks or enable 7-inch device OTA.
