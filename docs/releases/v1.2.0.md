# Project Aura v1.2.0

## STOP: READ THIS BEFORE UPDATING AURA 7-INCH

**DO NOT UPDATE AURA 7-INCH THROUGH OTA.**

**DO NOT TREAT v1.2.0 AS A NORMAL FIRMWARE UPDATE ON AURA 7-INCH. IF YOU
UPDATE THE FIRMWARE WITHOUT FOLLOWING THE COMPLETE 7-INCH PROCEDURE IN THE
GUIDE, YOU WILL DAMAGE YOUR BOARD.**

The 7-inch procedure covers the dedicated firmware, USB-UART installation,
new internal sensor wiring, the UART switch, updated printed parts, I²C pull-up
settings, and the checks required before power-on. Complete every step in the
published order:

[Read the Aura AQ v1.2.0 update guide](https://aura-aq.com/blog/aura-aq-1-2-0)

**THE GUIDE IS REQUIRED FOR BOTH DISPLAY SIZES.** Aura AQ 4.3-inch does not
need internal sensor rewiring, but it also has v1.2.0-specific update and
USB-C instructions. Read the guide before updating either board.

## Choose the correct update for your display

Aura AQ 4.3-inch and Aura AQ 7-inch now use separate firmware builds. Never
install firmware made for the other display size.

The stable firmware is marked explicitly everywhere it is shown:

- Aura AQ 4.3-inch: `1.2.0 - 4.3`
- Aura AQ 7-inch: `1.2.0 - 7-dual-i2c`

If the label does not match your display size, stop and do not install it.

### Aura AQ 4.3-inch

The 4.3-inch model does not need wiring changes. The attached
`project_aura_4_3_1.2.0_ota_firmware.bin` is for Aura AQ 4.3-inch only.

You can use OTA for the first move to v1.2.0 if your current firmware offers
the update. If OTA is unavailable or fails, follow the 4.3-inch wired-update
instructions in the guide.

### Aura AQ 7-inch

Do not use OTA. This GitHub Release does not include a 7-inch OTA BIN.

Open the enclosure and complete the full 7-inch procedure through the
[Aura AQ Web Installer](https://aura-aq.com/installer/aura-aq). Select the build
made for Aura AQ 7-inch and follow every step in the update guide.

After v1.2.0 is installed, the lower USB-C port on both models becomes the port
for power, future wired firmware installation, and serial logs.

## Extended diagnostics

If the display or touch stops working while the web dashboard remains
available, do not restart or unplug Aura. Open
`http://<your-aura-ip>/diag` and select **Download report**. Save the diagnostic
JSON before restarting, then attach it to your issue or support request.

## What changed

- Aura 4.3-inch and Aura 7-inch now have separate hardware-specific firmware
  builds.
- The 7-inch build includes fixes for display startup, touch operation, and
  unexpected reboots.
- Aura now records measurement history on an SD card and supports CSV export.
- Firmware updates, crash recovery, startup handling, sensor validation, and
  diagnostic reporting have been improved.
- Aura detects production and B4 SFA40 protocols, samples SFA30 and SFA40 once
  per second, and reports more SFA40 details in diagnostics.
- The HCHO card shows a localized `WARMUP` state instead of a stale value while
  the active SFA30 or SFA40 sensor is warming up.
- PR #154 improves the Japanese status messages.
